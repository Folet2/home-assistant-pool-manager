# Home Assistant Pool Manager

> **Smart Pool Automation for Home Assistant**

🤖 **PoolBot** is the official mascot of the project.

PoolBot is an open-source project that brings intelligent swimming pool automation to Home Assistant.

Designed with **reliability**, **simplicity** and **modularity** in mind, PoolBot helps automate pool filtration based on water temperature and is built to evolve into a complete swimming pool management platform.

---

## Why PoolBot?

Most Home Assistant pool automations start as a collection of scripts, timers and individual automations.

PoolBot takes a different approach.

It is designed from the ground up as a **coherent, modular and reliable platform** that can grow with your installation while remaining easy to understand and maintain.

---

## ✨ Features

### Current

- Intelligent filtration management
- Water temperature-based runtime calculation
- Multiple daily filtration cycles
- Home Assistant Package architecture
- Dashboard support
- ESPHome ready

### Planned

- Heat pump support
- Freeze protection
- Water chemistry (pH / ORP)
- Salt chlorinator management
- Pool lighting
- Energy monitoring
- Statistics
- Notifications
- HACS integration
