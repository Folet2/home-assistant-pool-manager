# Long-term Vision

PoolBot aims to become a modular ecosystem for swimming pool automation while remaining simple, reliable and easy to maintain.

Every new feature must respect the project's philosophy:

- Reliability before complexity.
- Simplicity before cleverness.
- Documentation before release.
- Real-world testing before publication.

---

**Keep the course.**
> The roadmap is intentionally flexible.
>
> Real-world testing and community feedback will always take precedence over planned features.
