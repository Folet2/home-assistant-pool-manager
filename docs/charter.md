# 📜 PoolBot Project Charter

> Keep the course.

---

## Our Purpose

PoolBot exists to build reliable, simple and maintainable swimming pool automation for Home Assistant.

Every decision should support this purpose.

---

## Our Principles

### Reliability first

Reliability always comes before new features.

If a choice must be made, we choose stability.

---

### Simplicity matters

Simple solutions are preferred over complex ones.

Complexity must always be justified.

---

### Real-world testing

Every major feature should be validated on a real swimming pool before release.

Field experience is as important as development.

---

### Documentation is a feature

Well-written documentation is part of the product.

Every new capability should be documented.

---

### Modular design

Users should be free to install only the components they need.

---

### Continuous improvement

PoolBot grows through small, carefully designed iterations.

No feature is ever considered finished.

---

## Our Rule

Before implementing any feature, ask:

- Does it solve a real problem?
- Is it easy to understand?
- Is it reliable?
- Can it be maintained?

If the answer is "no", rethink the solution.
